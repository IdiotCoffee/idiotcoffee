## 🔖 About Me

I'm a software engineer interested in understanding how complex systems behave and building tools that make them easier to reason about.

Over the past year I've worked on production AI systems while steadily moving deeper into distributed systems, observability, and developer infrastructure. I'm particularly interested in how software structure emerges across static code, runtime execution, and operational environments, and how that information can be surfaced to improve engineering decisions.

Outside of day-to-day product work, I spend a lot of time studying system design, backend architecture, and the internals of modern software platforms. My long-term goal is to build expertise at the intersection of AI, infrastructure, and large-scale systems engineering.
